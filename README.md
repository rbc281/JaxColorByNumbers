# Jax Color by Numbers 🎨

A safe, ad-free color-by-numbers game made for Jax.

## What's inside
- 50 playable pictures across Dinosaurs, Space, Polar Bears, Special Shapes, and Rainbows
- No ads, purchases, accounts, chat, or outbound links in the child UI
- Progress saved locally on the device
- Parent-gated settings
- Touch-friendly coloring, drag coloring, hints, zoom, and celebrations
- Installable PWA with offline caching

## Live site
After GitHub Pages finishes its first deployment, the project site is served from the repository's GitHub Pages URL.

## Privacy
The app itself sends no gameplay or child-profile data to an application backend. Progress/settings use browser localStorage. Standard hosting/network infrastructure may still receive normal web-request metadata.

## Content architecture
V1 uses one reusable coloring engine and locally generated picture data. More handcrafted art packs can be added without changing the core game.
